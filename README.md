### ผลกระทบลูกโซ่ ทีม 1 → 2 → 3 → 4

```
หาอ้อย ──▶ ตัด+ขน ──▶ ลานอ้อย ──▶ ลูกหีบ
```

* **ตัดไม่ทันที่หาไว้** → กองในไร่ล้น อ้อยส่วนเกินถูกโรงงานอื่นแย่ง · ความเชื่อมั่นชาวไร่ลด
  (ความเชื่อมั่นต่ำ = ทีมส่งเสริมหาอ้อยได้น้อยลงจริง)
* **ลานรับไม่ทัน** → รถต่อคิว · ชั่วโมงตัด-ถึง-หีบเพิ่ม · **CCS ตกชั่วโมงละ 0.042 หน่วย**
  (cane-brain: กลางฤดู 1.0 หน่วย/วัน) · เกิน 24 ชม. เกิด **dextran** · คิวเกิน 18 ชม. รถหนีไปโรงอื่น
* **ลูกหีบช้ากว่าลาน** → อ้อยกองค้าง เสื่อมต่อ เกิน 96 ชม. ต้องทิ้ง
* **ลูกหีบเร็วกว่าลาน** → เดินเครื่องเปล่า เสีย Time Efficiency
* ลงทุนเกินคอขวด = **เงินจม** (ทีมที่เกินจะชะลอตัวเอง ไม่ผลิตของทิ้ง)

ดูแถบ **"คอขวดของทั้งโรงงาน"** (แปลงทุกแผนกเป็นหน่วย *ตันอ้อย/วัน*) ในแท็บการผลิตได้ตลอดเวลา

### ค่าพลังเครื่องจักร และการเร่งเครื่อง

เครื่องจักรทั้ง 8 ตัว (ทีม 4-9, 11-12) เริ่มที่ **ค่าพลัง 100%** และลดลงทุกชั่วโมงที่เดินเครื่อง

| ดาว | ค่าพลังลด/วัน (เดินปกติ) | อยู่ได้ราว |
|---|---|---|
| 0 ดาว | 2.9% | 34 วัน |
| 5 ดาว | 1.2% | 87 วัน |

* กำลังผลิตจริง = ฐานตามดาว × เร่งเครื่อง × `0.45 + 0.55 × ค่าพลัง/100`
* **ค่าพลัง 0 = เครื่องพัง หยุดทั้งกระบวนการ** ซ่อมอย่างน้อย 1 วัน — **ลด 20% ต่อ 1 ดาวของทีมซ่อมบำรุง**
* **เร่งเครื่อง** 100 / 110 / 125 / 140 / 150% — กำลังเพิ่มทันทีโดยไม่ต้องลงทุน
  แต่ค่าพลังลดเร็วขึ้นแบบ **od³** (150% = เร็วขึ้น 3.4 เท่า) + พนักงานเหนื่อย + เสี่ยงอุบัติเหตุ/ไฟไหม้
* **หยุดล้างเครื่อง 1 วัน** ฟื้นค่าพลังทุกเครื่องพร้อมกันถึงเพดานของทีมซ่อมบำรุง (55% ที่ 0 ดาว → 100% ที่ 5 ดาว)
  พร้อมล้างตะกรันหม้อต้มและเปลี่ยนค้อน shredder
* ทีมซ่อมบำรุงจะ**ประเมินให้เอง**ว่าควรหยุดเมื่อไร (แถบคำแนะนำในแท็บการผลิต)

18 แผนก 4 กลุ่ม (สายวัตถุดิบ / สายการผลิต / พลังงาน / ทีมสนับสนุน)
แต่ละแผนกมี 4 หรือ 6 ระดับที่เป็นอุปกรณ์-ทีมงานจริง อัปทีละ 1 ดาว
หน้าอัปเกรดแสดง **ค่าที่เปลี่ยนจริง** ทุกพารามิเตอร์ (ปัจจุบัน → ถ้าอัปอีก 1 ดาว) และเน้นสีเขียว/แดงว่าดีขึ้นหรือแย่ลง
เครื่องจักรที่อัปเกรดจะได้**ค่าพลังคืน 100%** เพราะเปลี่ยนของใหม่

## เหตุการณ์สมจริง (EVENTS)

23 เหตุการณ์ 5 กลุ่ม มี **สาเหตุ · ผลกระทบเชิงปริมาณ · วิธีแก้** และหลายอันมี **ทางเลือกให้ตัดสินใจ**
หลายอันเกิดจากมือผู้เล่นเอง (`cond`) เช่น เร่งลูกหีบ > 125% → ลูกหีบตัน · pH > 7.5 → ตะกรัน ·
เร่งหม้อเคี่ยว > 125% → false grain · อ้อยไฟไหม้ > 25% → ภาครัฐตรวจ · ขวัญพนักงาน < 55 → เรียกร้องค่าจ้าง

## รายงาน

- **แท็บ KPI** = รายงานประจำวันผังเดียวกับโรงงานจริง + แถบสมดุล Pol + KPI เทียบเกณฑ์โลก
- **ภาพรวม** = คะแนน 6 ด้านแบบสด + คอขวดทั้งโรงงาน + สมดุลสายวัตถุดิบ
- **ปิดหีบ** ขายน้ำตาลค้างคลัง ปิดหนี้ แล้วออกรายงาน: เกรด S–F จากคะแนน 6 ด้าน
  รายรับ-รายจ่ายแยกหมวด (รวมดอกเบี้ยเงินกู้) จำนวนข้อร้องเรียนแยก 3 ทาง และบทวิเคราะห์
